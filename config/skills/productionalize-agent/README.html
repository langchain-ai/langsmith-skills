Inside Test

Evals you can actually trust

Sub-stepWhat happens
datasetFind issues — red-team workflow (parallel agents loop until they break it); maximize sample diversity, not size.
evaluatorsWhat matters to you? Pick dimensions — or "show me examples and I'll tell you what's good/bad." One feedback key = one test.
scoreRun the experiment → per-key pass/fail across every case.
alignAre the evaluators any good? Grade in an annotation queue → alignment % → iterate the eval prompts (train/test split, no overfitting).
fixAdjust the harness to fix any issues the suite uncovered; re-run until red→green, nothing regressed. The dataset becomes a permanent regression suite.
optimizeSweep models against the trusted suite → pick the cheapest / best-performing that still passes (resolves "choose for me").
hardenReduce eval cost; add a PR-triggered CI gate so quality can't silently regress.

FAQ

Common Questions

Will this work with an existing agent?

Yes — drop in at any phase. Point /test-agent (or any phase command) at an agent already in production; it inspects the code, framework, and existing traces, bootstraps the manifest, and hardens what's missing. You don't have to start at /build-agent.

Will this force me to use LangSmith for everything?

It centers the LangSmith stack for observability, evals, deployment, and monitoring — that's the point. But it's framework-neutral on the agent itself (deepagents, LangGraph, a Claude/OpenAI-SDK agent, or home-grown all work), and every phase is opt-in: run one command or all six. Nothing forces a rewrite.

Will this help me migrate to LangSmith?

It helps you instrument your current code to start getting traces into LangSmith. For a deeper migration from a similar product, we have a separate project — /migrate-from-* — built for that.

Can I customize the wizard?

Yes — it's built to be forked and fit to your org: pin approved models, swap auth / CI / frontend defaults, tune the teaching curriculum, and drop features you don't have (Engine, fleet). Forks sync upstream for new best practices, and field-discovered fixes can PR back.
