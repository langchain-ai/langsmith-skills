# LangSmith skills have moved

The `langsmith-*` skills in this package are deprecated and only point to their
replacements. Install the `langchain-skills` plugin from
https://github.com/langchain-ai/langchain-skills, following
https://github.com/langchain-ai/langchain-skills#migrate-from-the-standalone-skills.

Do not install, update, or remove skills or plugins without the user's go-ahead.
